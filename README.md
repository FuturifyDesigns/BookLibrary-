# Chapter House

A cozy independent bookstore site for GitHub Pages — with a hidden surprise for someone special.

Live: https://futurifydesigns.github.io/BookLibrary-/

## Pages

- `index.html` — bookstore home
- `login.html` — sign in / sign up (name-based gate, no database)
- `secret.html` — private chapter (unlocked by Laura’s name)

## Deploy

This repo is set up for GitHub Pages from the `main` branch root.
